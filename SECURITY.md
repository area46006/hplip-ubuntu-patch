# Security Policy

## Reporting Security Issues

If you discover a security vulnerability within the patches or scripts provided by this repository, please report it via GitHub Private Vulnerability Reporting or open an issue if it pertains to public open-source build tooling.

## Scope

- **In Scope**: Vulnerabilities in the scripts provided in this repository (`install.sh`), permission regressions introduced by our patches, or unsafe shell executions.
- **Out of Scope**: General vulnerabilities in upstream HPLIP or third-party device firmware. Upstream security issues should be reported directly to HP Product Security.
